# Agent 推广与项目落地：面向 AI 决策的经验

本项目编写一份面向管理层的英文报告，回顾米哈游在 agent 推广和项目落地方面的经验，包括作者在数据团队的工作。作者在更早任职的字节跳动的经历提供比较背景。报告旨在为作者当前公司的 AI 决策提供参考。同时维护对应的中文版，供作者核对是否存在遗漏或表述不准确的地方。

**状态：** 初步工作草稿。首批素材涉及作者于 2025 年 11 月加入米哈游、其从全公司视角了解到的 agent 项目稀少状况、其参与的数据团队项目、私有化部署的 Dify 受到的关注有限，以及字节跳动从 2023 年底到 2025 年底的对照经历。这些组织情况均归因于作者的回顾，尚未在本报告中获得独立佐证。Claude Sonnet 4.5 的发布日期已根据 Anthropic 的公告核对。完整回顾时间范围、详细案例结果、决策理由和建议仍待补充。

**中英文一致性：** 中英文报告及阅读说明必须在结构、事实、数字、日期、来源、证据状态、结论、建议、不确定性和待补信息上保持对应。任一语言版本的新增、删改、澄清或更正都必须在同一次修改中同步至两种语言，并在同一 Git commit 中发布。每次提交前以及 rebase 后、推送前，都要逐节核对两个版本。

报告将串联不同阶段和不同类型 agent 应用的经历，随证据积累纳入成功、失败及结果混合的案例，梳理公司对 AI 的态度、决策与组织反思随时间的发展，并呈现作者个人的看法。时间线依据所述事件的发生顺序整理，不以素材接收顺序为依据；后续阶段和应用分类将随更多素材逐步形成。公司立场与反思同作者的观察和判断予以区分。报告还分别标明作者回顾的经历、经公开来源核实的事实、解读和建议；有公开来源时提供链接。
