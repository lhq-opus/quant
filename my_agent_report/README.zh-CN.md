# Agent 推广与项目落地：面向 AI 决策的经验

本项目编写一份面向管理层的英文报告，回顾作者在前一家公司及部门过去一年推广 agent 和落地项目的经验，为作者当前公司的 AI 决策提供参考。同时维护对应的中文版，供作者核对是否存在遗漏或表述不准确的地方。

**状态：** 已初始化。目前报告仅包含大纲，尚未加入案例素材、证据、研究发现或建议。具体回顾起止时间和组织背景仍待确认。

**中英文一致性：** 中英文报告及阅读说明必须在结构、事实、数字、日期、来源、证据状态、结论、建议、不确定性和待补信息上保持对应。任一语言版本的新增、删改、澄清或更正都必须在同一次修改中同步至两种语言，并在同一 Git commit 中发布。每次提交前以及 rebase 后、推送前，都要逐节核对两个版本。

报告将串联不同阶段和不同类型 agent 应用的经历，覆盖成功、失败及结果混合的案例，梳理公司对 AI 的态度、决策与组织反思随时间的发展，并呈现作者个人的看法。时间线将依据所述事件的发生顺序整理，不以素材接收顺序为依据；阶段边界和应用分类仍待根据证据确定。公司立场与反思将同作者的观察和判断区分开来。报告还将分别标明作者回顾的经历、经公开来源核实的事实、解读和建议；有公开来源时提供链接。

交付产物采用便于转入 Confluence 的标准 Markdown 格式。发布到 Git 不等于发布 Confluence 页面。
