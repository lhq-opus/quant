# 阅读说明：从 Agent 推广到端到端交付

我为当前公司的管理层准备了[《从 Agent 推广到端到端交付：米哈游的决策与反思》](report.zh-CN.md)，以我在米哈游的 agent 开发工作和观察为基础，以更早的字节跳动经历作为比较背景。

[英文阅读说明](README.md) · [英文报告](report.md)

报告是第一人称工作草稿，当前覆盖 2025 年 11 月至 2026 年 7 月。主线是从激进推广 agent、个人单点提效，逐步转向共享基建，并尝试串联端到端工作流。这些重点存在重叠；流程串联仍有相当部分属于目标，尚不是已确认的全公司结果。

六个按时间排列的案例，均围绕**决策与行动、可能原因、关键结果**展开：

1. 2025 年 11—12 月：有限的起点与共享平台讨论。
2. 2026 年 1 月 OpenClaw 热潮之后：Echo 的广泛采用。
3. Echo 之后两三个月：框架与 skill 路线扩张，以及成本事件复盘。
4. 3—4 月：MCP、权限、推进落差与部门 OpenClaw 停用。
5. 4 月开始推动：Project S 的 harness 与数据飞轮、架构和设计缺口，以及我以 FDE 职责适配数据工作流的经历，包括端到端验收的限制。约两个月参与工作的具体起止时间仍待确认。
6. 5—7 月：harness、基建重构、OpenCode 二开的交付与验证框架，以及我推进的个人记忆系统。

报告区分公司立场、我的观察与判断，以及待我审阅的暂定分析。缺少测量时，关键结果保留为定性观察。文末提供暂定决策选项、重要证据缺口和来源。
