# Agent 推广与项目落地：米哈游的经验

**语言：** 简体中文 | [英文版](report.md)

**状态：** 初步工作草稿——已记录首批回顾素材，案例结果与分析仍不完整。

**读者：** 作者当前公司的管理层。

**目的：** 回顾米哈游及其数据团队在 agent 推广和项目落地方面的实践，为当前公司的 AI 决策提炼经验。作者更早任职的字节跳动提供比较背景。

**回顾时间范围：** 计划回顾一年的经历，但确切起止时间仍待确认。米哈游的首个时间参照点是作者于 2025 年 11 月入职；字节跳动的对照经历涉及 2023 年底至 2025 年底。

## 执行摘要

作者于 2025 年 11 月加入米哈游时，据其了解，全公司的 agent 项目很少，其在数据团队参与的工作正是其中之一。作者还回顾，公司内部已有私有化部署的 Dify，但在其所观察的整个时段内受到的关注有限。

作者认为，米哈游在 LLM 和 agent 应用方面的起步明显晚于字节跳动。据其回顾，字节跳动从 2023 年底在客服和内部研效中使用 LLM，逐步发展到 2025 年底已有工具能够完成某些长任务。详细结果及差异的原因仍待明确。

## 背景与范围

作者于 2025 年 11 月加入米哈游数据团队，从事 agent 开发；此前曾在字节跳动任职。正式职位名称及完整任职日期尚未提供。

作者已澄清，agent 项目稀少是其对米哈游全公司的了解，不局限于所在部门。这仍属于回顾性观察，并非已经核实、穷尽所有项目的清单。对照范围是 LLM 和 agent 的采用情况，不涉及两家公司在所有 AI 研究和应用领域的相对实力。

下文公司相关情况来自作者于 2026 年 9 月 17 日提供的回顾与澄清。目前报告纳入的公开证据仅核实了模型发布时间线。早期 LLM 使用与执行较长任务的 agent 予以区分；现有回顾不意味着字节跳动在 2023 年的所有应用都是 agent。

## 作者个人看法

作者认为，相比一线互联网公司，尤其是字节跳动，米哈游在 LLM 和 agent 应用方面起步明显偏晚。这是个人比较判断，并非全面的行业排名或量化成熟度评估。

作者回顾，在其入职时，自己认为 Claude Sonnet 4.5 是当时最优秀的模型。Anthropic 的公告确认该模型于 2025 年 9 月 29 日发布，早于该入职月份。发布日期支持时间背景；对模型优劣的评价仍归因于作者。参见 [Anthropic 发布公告](https://www.anthropic.com/news/claude-sonnet-4-5)。

作者对字节跳动工具的正面评价针对某些长任务。可靠性、任务时长、人工介入程度和业务影响尚未明确。作者如何了解这些工具在 2025 年底的情况也仍待补充；报告不假定其当时仍在字节跳动任职。
