# Agent Adoption and Delivery: Lessons for AI Decision-Making

This project develops an English report for leadership on lessons from agent adoption and project delivery at a previous company and department over the past year. Its purpose is to inform AI decisions at the author's current company. A corresponding Chinese version is maintained so the author can check for omissions or inaccurate wording.

Read the [working report](report.md).

[Chinese reading guide](README.zh-CN.md) · [Chinese report](report.zh-CN.md)

**Status:** Initialized. The report currently contains an outline; case material, evidence, findings, and recommendations have not yet been added. The exact review period and organizational context remain to be confirmed.

**Language consistency:** The English and Chinese reports and reading guides must remain aligned in structure, facts, numbers, dates, sources, evidence status, conclusions, recommendations, uncertainties, and open information gaps. Additions, deletions, clarifications, and corrections in either language must be reflected in both within the same update and published in the same Git commit. Both versions are reviewed section by section before each commit and again after rebasing, before pushing.

The report will connect experiences across stages and types of agent application, covering successful, unsuccessful, and mixed outcomes. It will trace the company's attitudes toward AI, decisions, and organizational reflection over time, alongside the author's personal views. The chronology will follow the events described, rather than the order in which material is received; stage boundaries and application categories remain to be established from the evidence. Company positions and reflection will be distinguished from the author's observations and judgments. Reported experience, publicly verified facts, interpretation, and recommendations will be identified separately, with links to public sources where available.

The deliverable is standard Markdown prepared for transfer to Confluence. Git publication does not publish a Confluence page.
