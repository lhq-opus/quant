# 逐行对比订单簿与答案

在 quant 仓库根目录执行，依赖为已有的 pandas：

```bash
python3 ./obr/script/compare_book_csv.py \
  --actual /path/to/my_book.csv \
  --expected /path/to/answer.csv \
  --output /path/to/book_diff.csv
```

`--actual` 是自己的 OBR 输出，`--expected` 是答案。省略 `--output` 时，差异文件
写到当前目录的 `book_diff.csv`。默认不覆盖已有文件；需要重跑时加 `--overwrite`。
即使加了该参数，也不能覆盖任何一份输入文件。

## 比较规则

- 第 n 条实际输出只与第 n 条答案比较，保持原始行顺序，不排序、不按 CAA join、
  不去重。重复 CAA 也逐条比较；长度不同的文件会报告缺少整行；
- 只比较以下21列，其他列忽略。两份输入的列顺序可以不同：

```text
caa,bp5,bp4,bp3,bp2,bp1,ap1,ap2,ap3,ap4,ap5,bs5,bs4,bs3,bs2,bs1,as1,as2,as3,as4,as5
```

- `caa` 按原始字符串精确比较，不解析时间、不丢弃前导零或小数位；
- 盘口价格和数量用 `Decimal` 按数值精确比较，`10`、`10.0`、`10.0000` 相等。
  不使用浮点容差、不舍入、不换算价格或数量单位；
- 两个空字段相等，空字段与 `0` 不相等。`NaN`、无穷大不是合法盘口值，不会判为一致；
- 按项目已有约定，缺少 `bp4` 但存在 `bo4` 时，将 `bo4` 作为买四价比较并打印提示。
  这只改变读取视图，不改原文件；两列同时存在时使用 `bp4`，忽略 `bo4`；
- 缺少必需列或盘口数值解析失败时直接报错，不生成看似成功的对比结果。

若答案与自己的输出使用不同的快照频率或空档表示，脚本会如实报告差异，不自动补行、
丢行或把空档填零。应先明确两份文件的输出口径是否相同。

## 差异文件

每个不一致字段占一条记录，原始值原样保留：

```text
data_row,field,actual_caa,expected_caa,actual_value,expected_value
```

`data_row` 是从1开始的数据记录号，不包含表头。通常数据记录1就是文件第2行。
`field` 是不一致的字段名；整行缺失时写 `__row__`，两边的值分别标记“存在整行”
或“缺少整行”。CAA 不同时，仍会检查同位置的盘口字段，不隐藏其他差异。

终端打印两份文件行数、不一致行数、差异数及前10处差异；完整差异在 CSV 中。
全部一致时差异文件只含表头，退出码为0；存在差异时退出码为1，读取/写入错误也非0。
所有 CSV 都由 pandas 读写，脚本可独立执行，不需要先调用其他 Python 脚本。
