# Method 3：共同出现的关系轮廓 + 单一核心簇补全

## 结论

**独立得到覆盖全部 1,451 股的六组，成员与 method1 完全一致。** 本方法不读取首轮扫描片段，不删除扫描记录，不使用 method1 的邻接边或组号，也不预设六组。区别在于：先比较每只股票与其他股票共同出现的整体关系，再识别大分量，最后由一致的局部观测补齐少数成员。

## 分组方法

### 1. 用 clock 构造共同出现次数

在输入原序中，相邻 `clock` 差大于 3,000 时切开，得到 120,110 个观测簇。一个簇内同一股票只计一次出现。记 `C(i,j)` 为两股共同出现的簇数，`N(i)` 为股票 i 参与的簇数：

```text
A(i,j) = C(i,j) / sqrt(N(i) * N(j))，i != j
A(i,i) = 0
```

这一步校正活跃度：同样共同出现 100 次，对一天只出现 200 次和出现 4,000 次的股票，含义不同。观测簇只是计算单位，不等于真实 push 或 snapshot；可以混组，也可以含同股重复记录。

### 2. 比较“与其他股票的关系”

把 `A(i,:)` 这一整行看作股票 i 的关系轮廓：它与哪些股票经常一起出现、与哪些股票较少一起出现。计算两行的余弦相似度：

```text
P(i,j) = dot(A(i,:), A(j,:)) / (norm(A(i,:)) * norm(A(j,:)))
```

即使 i 和 j 本身偶尔没有一起出现，只要它们经常与同一批其他股票一起出现，轮廓仍可能接近。该指标与“i、j 直接共同出现的比例”不同。

`P(i,j) >= 0.9` 时连无向边，求连通分量。默认得到 25 个分量：六个大分量有 134–269 股，其余分量只有 1–2 股。选至少 50 股的分量作为核心，自动得到六个核心组，共 1,431 股。这里没有调用谱聚类、KMeans 或指定组数。

“50”是防止把一两股共享扫描背景误当成大组的探索门槛；在当前图上，任意整数门槛 3–134 都会选中相同六个大分量。已实际检查 20、30、50、80、100，核心成员及组号完全一致。

### 3. 以无冲突的局部支持补齐 20 股

冻结上述核心组，在原始 3,000-gap 观测簇中寻找：

1. 至少包含 20 只不同核心股票；
2. 核心股票只来自一个核心组。

某只非核心股票出现在这样的簇中，就获得一个候选归属。**必须检查该股所有符合条件的支持簇都指向同一个组**；如果出现矛盾或无支持，脚本报错，不默默投票或输出空值。当前 20 股全部有支持、归属均无矛盾，共 6,806 条支持记录，来自 6,030 个不同观测簇。

这 20 股里，15 股分别有 262–703 个支持簇；另外五股证据明显少，不能把它们的完整标签描述成同等可靠：

## 参数与分片核验

### 参数敏感性

- `gap=2000/3000/5000/10000` 与轮廓阈值 `0.85/0.9/0.95` 的 12 个组合，均自动得到六个大分量，并补全成同一份 1,451 股映射。不同设置的核心集合可不同，当前检查到核心覆盖 1,416–1,442 股；最终成员一致。
- `gap=1800` 的三个轮廓阈值都缺少 `603330` 的合格补全簇，其他支持没有矛盾；因此这三个设置不能满足全覆盖，已保留失败记录。
- 默认 `gap=3000, P>=0.9` 下，大分量门槛 20/30/50/80/100 不改变核心；补全所需核心股票门槛 10/20/30/50 不改变完整映射。
- 探索中把轮廓阈值降到约 0.6–0.79，扫描背景能把少数弱股接错；不能无限降低门槛来追求核心覆盖。只对原始共同出现余弦设强边，或仅按观测簇大小直接合并，也不能可靠得到完整六组。

## 与“组内所有股票遵循规则”的关系

这是明确的两阶段观测规则：核心由整体关系轮廓相近的路径连接，非核心成员由所有可判定局部支持的一致归属加入。全部股票都有可追溯的证据路径；没有以“不确定”为由漏掉股票。不能改述为“任意同组股票对都满足 `P>=0.9`”，也不能说“任意观测簇都不混组”。

这套方法提供了与 method1 实质不同的独立支持，**不提供任意组内两股都满足同一直接阈值的证明**。若要求一条对任意成员对直接成立的必要且充分条件，它仍未达到该更强标准。它也不证明上游真实业务恰好六组：始终同步的更细组和更粗调度层级仍可能产生相似观测。多个方法在同一天数据上成员一致，不等于独立真值认证。
