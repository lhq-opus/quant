# 当前六组是否存在全部成员遵循的共同规则

## 结论

**找到一条能从原始数据独立重建当前六组的规则。** 它只使用首轮扫描片段和短时间相邻关系，不读取现有六组标签决定成员。全部 1,451 股都有联系；本目录主结果为 [stock_groups.csv](stock_groups.csv)，与历史 `stock_groups_complete.csv` 逐股完全一致。

对任意两条相邻记录，若两股来自不同的初始扫描片段，且 `clock` 差不超过 100 原始单位，就建立一条无向联系。直接或间接相连的股票归入同一个连通集合。

因此每个集合的共同性质是：**所有成员都能通过这种联系相互连接，所有符合条件的邻居都留在该集合内。** 是否有直接联系不要求组内每对股票都相同；例如 A 与 B、B 与 C 有联系，即可把三者连接起来。

## 初始扫描片段如何确定

首 1,451 条记录恰好是股票全集，各股一次。以相邻 `clock` 差大于 100,000 切开，得到 30 个片段。这个步骤只读取原始数据。

首轮片段内相邻间隔最大 11,683，片段之间最小 932,859，切点位于明显空档。先前独立顺序检查还发现这些完整片段全天周期性重现。一个扫描片段混合多个同步组，因此同片段内的短时间接近不用于本规则建立分组联系。这里没有根据当前组号过滤反例，也没有宣称已识别或删除了全部扫描记录。

## 阈值与适用范围

- 阈值 10、20、50、100、200 时，全量均生成完全相同的六组，后半也一样。阈值 5 时另有两只孤立股票。
- 第一个跨初始扫描片段、也跨当前六组的相邻反例出现在间隔 211：数据行 331866 的 `601360` 与行 331867 的 `603788`。行号从 1 开始，不含表头。阈值升至 500 时，所有股票已连成一个集合。
- 这说明“小间隔”的条件必须写清楚。不能把规则改成任意时间距离下的共现均须同组。
- 六个连通集合是这条具体构图规则的确定结果。它仍不是上游真实推送或业务组数的认证：仅有“存在联系则同组”的单向约束时，进一步合并某些集合也不会产生该约束的反例。选择连通分量相当于保留最细的、由这些联系所要求的集合。
- 全量和留出数据中的无反例是观测事实；未来数据仍可检验并推翻它。低活跃五股的连接证据较少这一限制继续保留。

## 与原先统计分组的关系

此前谱聚类提供了六组候选，但没有给出这个严格构图规则。本轮为检验所有成员共同遵循的性质，重新检查跨扫描片段的短间隔联系：先发现小时间簇共现图恰好有六个连通集合，再简化到直接相邻记录，仍恢复完全相同成员。新规则支持既有完整结果，没有修改映射。

简单的“每股与本组平均同步强度始终最强”在较大阈值下会被弱证据股违反，见历史 [rule_member_summary.csv](../../../../mds_v2_exploration_20260915/rule_member_summary.csv) 和 [rule_member_counterexamples.csv](../../../../mds_v2_exploration_20260915/rule_member_counterexamples.csv)。这种平均统计准则不应代替本页的明确关系规则。周期、相位等时间规则的检查另作边界对照，不影响本页组合条件的验证。

独立全源重算的短簇共现图佐证见 [rule_pair_README.md](../../../../mds_v2_exploration_20260915/rule_pair_README.md)，周期与单一距离规则的具体反例见 [rule_clock_README.md](../../../../mds_v2_exploration_20260915/rule_clock_README.md)。同簇共现版本包含 72,165 条边，与直接相邻版本的 16,187 条边定义不同，两者都独立得到相同完整成员。

## 本轮独立审查补充

- 相邻股票按出现方向统计为 16,187 条边；其中没有任何股票对同时出现正反两个方向，因此当前无向不同对数也为 16,187。程序以无向图求分量，方向不决定归组。
- 全量完整六组的最小整数 gap 阈值是 **7**。结合首个跨当前组的合格关系在 211，整数阈值 **7–210** 均得到相同完整六组。这是当前文件的分离范围。
- 仅保留出现至少 100 次的相邻关系，仍得到同样的 1,446 股核心成员；要求每条关系在全部八个等记录数分片都出现，也得到同样核心成员。五只弱证据股不能通过这种重复门槛。
- 全图恰有三条桥，即删掉该关系就会断开的边，分别连接 `600131`、`600485`、`603330`，各仅出现一次。其余弱股也依赖少量末段记录。完整覆盖与重复证据强度应分别阅读。
