## method2 的共同规则

先记下每只股票在首个完整排列中的位置 `r(stock_id)`。对于全天每一对原始相邻记录 `a → b`，计算：

```text
gap = clock(b) - clock(a)
jump = r(b) - r(a)

建立联系：gap <= 100，且 jump 不在 [1, 10] 内。
```

排除小幅顺行，是为了过滤重复扫描及少量跳过股票时形成的邻接。反向或更大幅度的跳跃提供另一类同步联系。最后把直接或间接相连的股票归在一起。

**全部成员适用同一规则：每组在这种联系下连通，任何符合条件的邻居都留在同组。** 组内任意两股不必直接相邻或直接共现。

- 默认有 3,334,218 次合格相邻观测、16,191 对联系，得到六组且无孤立股票。
- `clock` 阈值 10、20、50、100、200，以及小幅顺行排除范围 5、6、10、20、50、100、200 的已检设置，都支持同一完整成员划分。阈值是探索参数，不是已确认的业务常量。
- 冻结前半独立得到的 1,446 股核心分组，后半 1,640,663 次两端已知的合格邻接没有跨组冲突。五只弱股在后半获得补全联系。
- 仅按完整覆盖筛出的 228 个候选全量排列全部与首轮逐位同序，其中 142 个来自后半。筛选没有以“顺序相同”为前提。

同数据建图后没有跨分量边，是连通分量定义保证的；**冻结前半结果再检查后半**，才提供额外的外推证据。method1 与 method2 的过滤目标相近、证据大量重合，不将它们算作两份独立数据。

## method3 带来的独立证据

按 `clock` 相邻差切出观测簇，计算每对股票共同参与的次数，除以双方参与次数的几何均值。每只股票因此得到一条“与其他股票的共现关系”向量。比较这些向量的余弦相似度，将大连通分量作为核心，再检查剩余股票在单一核心组的观测簇中的归属。

默认设置自动得到六个大核心分量、1,431 股；其余 20 股经所有合格局部支持一致地补全，得到相同的完整六组。没有读取 method1 或 method2 的标签，也没有使用初始扫描片段。详细公式、失败设置和分时段结果见 [method3 说明](method3/README.md)。

这是另一种统计证据。它不承诺组内任意两只股票的原始距离或两两余弦相似度始终达标，也不能把观测簇认作已经确认的真实推送。

## 最新 method4：固定时间网格与谱分组

以宽度30000的固定clock格子统计股票二元出现，平均0、7500、15000、22500四个起点的直接同步矩阵，再用归一化拉普拉斯谱的最大相邻间隙自动选择组数。默认自动六组；1446股通过平均同步核心条件，另5股由以自身到达为中心的固定时间窗口一致补全，最终成员与前三种方法完全相同。

宽度20000–50000的已检设置、1/2/4/8起点及多档核心/局部窗口门槛均支持同一完整结果。冻结前半1446股核心，后半全部1446股对本组平均同步都严格高于其他组，最小比值1.96243；五股在后半补全。细表见 [method4](method4/README.md)。

本轮同时检查了窄网格的11组候选：半格平移会改变9股，第一四分片会选17组，尚不支持将11当作稳定业务组数。另有明确限制：完整映射中的600086、600131、600145、600485不满足“全日对本组平均同步最强”，所以method4是统计核心加局部补全的两阶段方案，不能称为适用于全部成员的一条平均同步定律。

## 证据强弱与本轮否定的规则

最需要区别对待的仍是 `600086、600131、600145、600485、603330`。它们全部已经分组，但独立额外到达证据少：600086 有三条支持，其他四股各一条。method1 中有三条只有一次观测的桥，删除其中任何一条，便会让相应股票失去连接。全部六组直到原始数据第 5,014,692 行（约 99.38%）才首次完整连通。

相对而言，要求一条联系在全部八个等记录分片中都出现，仍有 5,249 条联系连接相同的 1,446 股核心。这区分了主体的重复证据与弱股的补全证据。详见 [独立审查](../../../v2_grouping_exploration_20260915/audit/README.md)。

另外检查了 128 个简单股票代码特征（前缀、数字和及取模），全部有反例；各组更新次数范围也广泛重叠。代码前缀、奇偶性、频次区间不能替代当前的顺序和同步规则。见 [股票代码与频次检查](../../../v2_grouping_exploration_20260915/identifiers/README.md)。

**本轮没有发现一份证据更强且成员不同的划分。** 六组是这些具体方法支持的完整候选，尚不能认证上游真实业务恰有六组。仅靠“有联系则同组”的约束无法排除进一步合并；同组所有股票每次一起到达、各组互不重叠的固定 clock 区间等更强性质，也未获得证明。
