## 全部成员遵循的规则

首个重复股票之前有 1,451 条记录，恰好是全部股票各一次。将此排列中的位置记为 `r(stock_id)`，从 0 开始。这里的排名不是股票 ID 的数值大小。

对于原始 CSV 中任意相邻记录 `a → b`，计算：

```text
clock_gap = clock(b) - clock(a)
rank_jump = r(b) - r(a)
```

两项条件同时满足时，在 `a`、`b` 之间建立无向联系：

1. `1 ≤ clock_gap ≤ 100`；
2. `rank_jump` 不在 `1..10` 内，即排除参考排列中向前走 1 至 10 位的局部顺行。

最终取这些联系的连通分量。每组具有同一个可检验性质：**全部成员通过这种联系直接或间接相连，所有符合条件的相邻股票都属于同组。** 不要求组内任意两只股票都有直接边，也不要求同组股票在整个 CSV 中连续出现。

例如，首轮排名从 40 到 41 或 46 的短间隔相邻暂不提供分组联系；从 400 到 120，或从 40 到 170 的短间隔相邻提供联系。过滤意图是减少固定顺序扫描及少量跳过造成的背景关系。这是数据支持的解释，不是已知上游实现。

`100` 和 `10` 是本次探索选择的参数，原始 `clock` 的整数单位保持不变；两者均不是事先给定的业务绝对边界。

## 参数平台和真实反例

固定时差上限为 100，改变排除的正向排名步数 `L`：

| 排除范围 | 连通分量数 | 说明 |
|---|---:|---|
| 不排除、`1..1`、`1..2` | 1 | 局部扫描关系仍会连接所有股票 |
| `1..3` | 3 | 规模 137 / 522 / 792 |
| `1..4` | 5 | 两个六组候选被连接为 541 股 |
| `1..5`、`1..6`、`1..10`、`1..20`、`1..50`、`1..100`、`1..200` | 6 | 已检查的这七档成员完全相同 |
| `1..500` | 7 | 过度删边，出现一只孤点 |
| `1..1000` | 9 | 出现三只孤点 |

时差上限 `10/20/50/100/200` 下，上述七档稳定设置都得到完整的同一六组。默认 `L=10` 位于这个已观察平台中，保留较多关系，并比最小稳定设置 `L=5` 多留少量过滤余量；它不是被证明唯一最佳的数值。

两种放松均有实际反例：

- **只排除到 4 位不够。** 数据行 `4849134 → 4849135` 为 `600781 → 600421`，`clock_gap=7`、`rank_jump=+5`，属于本次六组中的不同组。该股票对全天还有另一次 `gap=13` 的相同类型观测。
- **时差不能随意放宽。** 数据行 `331866 → 331867` 为 `601360 → 603788`，`rank_jump=-476`，在 `gap=211` 首次出现跨本次六组的合格顺序跳变。默认顺序过滤下，时差 211 得 5 组，250 得 2 组，500 得 1 组。

反例行号从 1 开始，不含表头。时差上限 5 又过于苛刻，会留下两只孤点。上述边界说明两个筛选条件各自有作用。

## 与 method1 的区别及解释边界

method1 排除“同初始扫描片段”；本方法排除“首轮排名局部顺行”。默认时差相同，本方法比 method1 多保留 4 个股票对、4 次观测，仍得到同一成员划分。两条规则共同支持同一六组，但使用同一天、相关的背景过滤思路，不应表述成两个独立数据来源的真值认证。

连通分量给出由合格联系要求的最细闭合集合。仅有“有联系则同组”的正联系规则，进一步合并某些集合也不会违反它；因此不能从本规则证明上游业务恰好只有六组。30 个重复扫描片段也属于另一种观测结构，不能直接当作这六组的替代真值。新的一天若出现反例，应重新评估规则。
