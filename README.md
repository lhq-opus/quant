# quant

Market Data Study（MDS）研究项目。

本项目研究如何仅根据一天内的股票 `stock_id` 和源系统 `timestamp`，恢复上游长期固定的股票分组。一次隐藏推送只属于一个组，但可能只包含该组中当时发生变化的部分股票；不同组的推送偶尔会在时间上非常接近。

## 当前状态

项目仍处于问题建模和方案讨论阶段，尚未选定或实现最终分组算法。

当前讨论主线包括：

1. 在时间邻域内生成候选股票对；
2. 对候选股票对的全天时间序列做一对一匹配；
3. 使用多个时间窗口构造同步曲线；
4. 根据全日或局部更新强度估计偶然碰撞；
5. 将可靠关系构造成加权图并恢复固定分组；
6. 使用时间切片和不确定性评估验证结果。

## 项目文件

- `AGENTS.md`：项目背景、已确认假设、工作约定和验证原则。
- `discussion.md`：讨论进度、候选方案、失败方案和未决问题。
- `data/sample_market_data.csv`：教学用算法输入，仅包含 `stock_id,timestamp`。
- `data/sample_ground_truth.csv`：教学样例的独立真实分组，仅用于评估，不得作为算法输入。

## 数据说明

真实 CSV 无法提供，因此后续验证需要生成带隐藏 `push_id` 和真实 `group_id` 的模拟数据。待测算法只能读取真实业务输入会拥有的字段，不能使用模拟真值标签。

开始新的讨论或开发任务前，请先完整阅读 `AGENTS.md` 和 `discussion.md`。
